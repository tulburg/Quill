The untouched fork does not build here: GPUI compiles its Metal shaders at build time, and this Mac's Xcode is missing the Metal Toolchain (Xcode now downloads it separately). Nothing in the code is wrong.

- A. You run `xcodebuild -downloadComponent MetalToolchain` once (an Apple download, about 700 MB), and the build stays exactly as upstream (recommended)
- B. Turn on GPUI's `runtime_shaders` feature for dev builds so shaders compile at launch, and keep build-time shaders for release builds
- C. Both: B now so work can continue, A before packaging
