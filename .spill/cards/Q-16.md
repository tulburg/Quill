Quill still carries Quiet.md's version (0.1.9 in Cargo.toml) and its changelog in src/changelog.rs, including Windows entries and a 0.1.5 line rewritten to say "The app is now called Quill", which never happened. The changelog card shows after an update, so this is only visible once a second Quill version ships.

- A. Start at 0.1.0 with an empty changelog; Quill's own notes begin with its next version (recommended)
- B. Keep 0.1.9 and Quiet.md's history, but restore the original 0.1.5 line and drop the Windows entries
- C. Leave both as they are
