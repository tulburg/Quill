User's own answer (redirect on Q-17): "Think of it as two different instances of the same app. Both can exist at the same time. If launched from the menu bar, it just another instance with a different configuration. If launched from the applications folder or other app launch method, it opens as a window."

This replaces the move-between-modes model from D-12 for the window part (D-12's "the menu shows the exact main window" still holds for what is drawn). Worked out in S-10.
