## Purpose
Quill lives in the macOS menu bar by default: its status item shows the exact Quill main window, anchored under the icon. There is no separate panel UI or second window: the same main window moves between the menu bar and a standard window (D-12). Standalone, Quill behaves exactly like Quiet.md.

## Requirements
1. On launch Quill adds a status item (template icon, adapts to light/dark menu bar) and, in menu bar mode, shows no Dock icon and no app switcher entry.
2. Left-click shows or hides the main window, attached under the status item as a popover with an arrow (D-5), on the display that holds the icon; right-click (or Control-click) opens a menu: New Note, Open in Window, Settings, Quit.
3. What shows is the main window itself: the same Workspace (sidebar, Home, tree, search, editor, settings), drawn exactly as in standalone. Nothing is removed and no custom panel UI is added (the S-8 field is the only addition).
4. In menu bar mode the window hides when you click elsewhere (D-5), on Esc when no menu or editor popover is open, and on clicking the status item again; hiding saves the open note first.
5. Showing it again restores where the user was (open note or Home).
6. "Open in Window" detaches the same window into a standard window (title bar, resizable, Dock icon shown while it is open, D-7 B); a matching command attaches it back to the menu bar. Settings > General > "Run from menu bar" picks which mode Quill starts in.
7. No default global shortcut (D-6); the user can set one in the shortcuts panel to show and hide the window.
8. Settings > General > "Launch at login", off by default (D-7 A).
9. Works on multiple displays and with the menu bar auto-hidden.

## Out of scope
The New note field and its transition (S-8). Windows and Linux (removed, D-1).

## Acceptance checks
- Launch: status item visible, no Dock icon.
- Click: the main window appears under the icon, identical to standalone; click elsewhere: it hides and note edits are on disk.
- Open in Window: the same window, same note, becomes a standard window and the Dock icon appears; attaching it back hides the Dock icon.
- "Run from menu bar" off, relaunch: Quill starts as a standard app.
- Launch at login toggles a login item.
