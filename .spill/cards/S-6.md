## Purpose
Quiet.md's license requires forks to replace the name, the app icon and the 67 Nucleo icons in `assets/icons/` (commercial license, not MIT). Quill needs its own identity so it can sit next to Quiet.md on the same Mac without sharing settings, windows or data by accident.

## Requirements
1. Product name Quill everywhere in the UI, menus, About, window titles and the bundled Getting started guide (English and Simplified Chinese).
2. Own crate/binary name (`quill`), bundle id, and app data/recovery/log directories, so Quill and Quiet.md never share state.
3. Default library location as decided in the library question.
4. A Quill app icon and menu bar template icon.
5. Every Nucleo icon replaced per the icon question; THIRD_PARTY.md updated to match.
6. The in-app updater no longer points at download.quiet.md (per the updater question).
7. Packaging scripts produce `Quill.app`.

## Out of scope
Menu bar behavior. Feature changes.

## Acceptance checks
- `grep -ri quiet` over src, assets and guides finds only license/attribution lines.
- Quill and an installed Quiet.md run side by side with separate settings.
- No file from `assets/icons/` Nucleo set remains.
