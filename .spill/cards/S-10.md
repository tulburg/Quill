## Purpose
D-17: the menu bar and the app window are two instances of the same app that can be open at the same time, each with its own configuration. Opening Quill the usual way (Applications, Dock, Spotlight, Finder) gives a standard window; the status item gives the menu bar window, set up for quick capture. Today (S-7) there is one window that moves between the two, which is what made the Dock icon question (Q-17) awkward.

## Requirements
1. Both are windows of one running Quill (one process, one library), so a note edited in one shows in the other and saves are never fought over. "Instance" here means a window with its own configuration, not a second process.
2. The status item is always there while Quill runs. Clicking it shows or hides the menu bar window: attached under the icon with the arrow, fixed size, hides on click elsewhere, Esc and Cmd-W (as S-7 today).
3. The menu bar window's own configuration: the sidebar is hidden when it opens (Cmd-] still shows it for that window), and the S-8 New note field sits at the top of Home to start a note in one click.
4. Launching Quill from Applications, the Dock, Spotlight or Finder opens a standard window (title bar, resizable, remembered size, sidebar shown, no New note field), exactly like Quiet.md. Launching again while Quill is running (Dock click, reopen) brings that window forward, or opens one if none is open.
5. Both can be open at once and each keeps its own place (open note or Home, sidebar shown or hidden).
6. Dock icon: shown while a standard window is open, hidden when only the menu bar window is (the D-7 B rule; closing the last standard window removes it).
7. Launch at login (D-7 A) starts Quill with only the status item: no window.
8. The status item menu: New Note, Open Window (opens or focuses a standard window), Settings, Quit. "Attach to Menu Bar" and the Quill menu's "Open in Window" / "Attach to Menu Bar" items go away.
9. Settings > General > "Run from menu bar" goes away (there is nothing to pick between). The "Show or hide Quill" global shortcut toggles the menu bar window.
10. The menu bar window's size is never recorded as the standard window's size (folds in the S-9 review bug).

## Out of scope
S-8's transition itself (unchanged). A second process or a second library.

## Acceptance checks
- Open Quill from Applications: a standard window with the sidebar and a Dock icon; the status item is there too.
- Click the status item: the menu bar window appears under it with no sidebar and the New note field on top, while the standard window stays open; edit a note in one, the other shows the edit.
- Cmd-] in the menu bar window shows its sidebar without changing the standard window.
- Close the standard window: the Dock icon goes; the menu bar window still works.
- Quit, relaunch from Applications: the standard window opens at its last size, not 960 x 640.
- Launch at login: only the status item, no window, no Dock icon.
- check.sh passes.
