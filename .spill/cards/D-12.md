User, answering the S-8 design review: "There shouldn't be a custom UI or window, it should be the exact window of the main window that shows up in the menu." So the menu bar shows the main window itself, the same one that becomes a standard window when toggled, with no custom panel UI and no second window. The S-8 frames (main window as is, plus the New note field and its transition) follow this; S-7 is rewritten to match.
