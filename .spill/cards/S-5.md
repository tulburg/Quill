## Purpose
Quill starts as an exact copy of Quiet.md 0.1.9 (upstream `s1dashu/quiet-md`, commit 57884b9). Before any Quill change, the fork must build, pass upstream checks, and run with every Quiet.md feature intact, so later specs only add to a known-good base.

## Requirements
1. The repo is a clone of upstream with the `upstream` remote kept, so upstream fixes can be merged later.
2. `cargo build --release` succeeds on macOS (Apple Silicon) with the vendored GPUI and Taffy patches.
3. `scripts/check.sh` passes (cargo test --release, clippy zero warnings).
4. The preview app launches as a normal windowed app against a temp library (`QUIET_MD_HOME`), never the real `~/Documents/Quiet.md`.
5. Every upstream feature works unchanged: editor blocks, slash menu, tree, pin, favorites, search, trash, import/export (Markdown, DocxXML, PDF, print), shortcuts panel and rebinding, themes and dark mode, Option+Space quick note.

## Out of scope
Renaming, icons, menu bar mode, the new entry field (later specs).

## Acceptance checks
- check.sh exits 0.
- App opens on a temp library and the Getting started guide appears.
- A note created, edited, searched, trashed and restored round-trips on disk.
