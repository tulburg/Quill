After Open in Window, closing that window (Cmd-W or the red button) leaves Quill running with its Dock icon, but no window. D-7 says the Dock icon shows while a standalone window is open.

- A. When Run from menu bar is on, closing the detached window puts it back in the menu bar (hidden, no Dock icon) (recommended)
- B. Only hide the Dock icon; the next status item click opens a standard window again
- C. Keep it as is (like Quiet.md: the app stays in the Dock)

## Comments
- User (2026-11-10): Redirect: You’re thinking about it wrongly. Think of it as two different instances of the same app. Both can exist at the same time. If launched from the menu bar, it just another instance with a different configuration. If launched from the applications folder or other app launch method, it opens as a window.
