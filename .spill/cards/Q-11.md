S-6 now carries the rename, its own data paths, the updater removal, 67 icon swaps, a new app icon, and (from D-1) removing all Windows and Linux code. That is too big to build and check as one piece. Proposed parts, each a child of S-6, built in this order:

1. **Remove Windows and Linux** (D-1, Q-4): cfg(windows/linux) code, WebView2/registry deps, packaging/windows, Linux scripts, CI jobs. Check: macOS build and check.sh still pass.
2. **Name and data identity** (Reqs 1, 2, 3, 7; Q-1/D-2): Quill name in UI and guides (EN, zh-CN), binary `quill`, bundle id, `~/Documents/Quill`, own app-data/recovery/log dirs, `QUILL_HOME`, packaging makes Quill.app.
3. **Remove the updater** (Req 6; Q-3/D-4): update.rs, the sidebar Update button, the Settings toggle, minisign dep, release/publish scripts.
4. **Icons** (Reqs 4, 5; Q-2/D-3): 67 Nucleo icons to Lucide, THIRD_PARTY.md, plus a Quill app icon and menu bar template icon, drawn on the card first.

S-6 then becomes the overview.

- A. Split as proposed (recommended)
- B. Keep S-6 as one spec
