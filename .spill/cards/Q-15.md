S-7 is built and these pass here: status item with the feather, no Dock icon, the window under the icon with the arrow, toggle, hide when another app activates, Open in Window and attach back (Dock icon on and off), the status menu, Run from menu bar off starts a standard window, the General and Shortcuts rows, check.sh.

These need your hands; this Mac gives me no clicks or keys outside the test harness:
1. Click the feather: the window appears under it and takes focus. Click another app: it hides.
2. Esc on Home hides it; Cmd-W hides it. Type in a note, click away, reopen: the edit is there.
3. Right-click the feather: New Note, Open in Window, Settings, Quit each work.
4. Settings > Shortcuts > Show or hide Quill: record a key and use it from another app.
5. Settings > General > Launch at login: build with `SIGNING_IDENTITY=- scripts/release.sh`, run that Quill.app, turn it on, and check System Settings > Login Items.
6. D-13: with Reduce Motion on, the New note field cross-fades instead of sliding.
7. If you have a second display or an auto-hidden menu bar: the window opens under the icon there.

Esc inside a note still selects the block (Quiet.md behavior), so Esc hides the window only when no note or field has the caret.
